# Contributing

Early stage. The most useful thing you can send is a disagreement with the design, opened as an issue, with the case that breaks it.

## Before a pull request

- Open an issue first for anything larger than a typo, so the design is agreed before the code exists.
- One change per pull request.
- A claim in a document needs a source in the same pull request. This project is about evidence, so it holds itself to the same rule.

## What is out of scope

- Features that make the factory faster while making the record weaker.
- Anything that lets the thing being verified write to the verification record.
